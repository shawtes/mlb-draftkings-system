TROUBLESHOOTING
===============

Issue: Permission denied (publickey)
Fix: Make sure you're using the correct username
     Check: ssh stesfaye4@snowball.cs.gsu.edu

Issue: Files not found after upload
Fix: Check if you're in the right directory
     Run: pwd
     Should show: /home/stesfaye4

Issue: gcc not found
Fix: Load gcc module
     Run: module load gcc
     Or: module avail (to see available modules)

Issue: Cannot compile
Fix: Check file contents
     Run: cat part2.c | head -10
