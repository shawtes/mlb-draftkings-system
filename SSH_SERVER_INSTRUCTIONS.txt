SSH SERVER SETUP INSTRUCTIONS FOR C LAB
==========================================

STEP 1: TRANSFER FILES TO SERVER
==========================================

Option A: Using SCP (Secure Copy)
----------------------------------
From your local machine terminal:

scp part1a.c your_username@server_address:~/
scp part1a_answer.txt your_username@server_address:~/
scp part1b_answer.txt your_username@server_address:~/
scp part2.c your_username@server_address:~/
scp part2_answer.txt your_username@server_address:~/
scp part3.c your_username@server_address:~/
scp part4.c your_username@server_address:~/

Or transfer all at once:
scp part*.c part*.txt your_username@server_address:~/

Replace:
- your_username = your school username
- server_address = your school server (e.g., cs.school.edu)


Option B: Using SFTP
--------------------
sftp your_username@server_address
put part1a.c
put part1a_answer.txt
put part1b_answer.txt
put part2.c
put part2_answer.txt
put part3.c
put part4.c
exit


Option C: Copy-Paste Method
----------------------------
1. SSH into server: ssh your_username@server_address
2. Create each file manually:
   nano part1a.c
   (paste content, press Ctrl+X, Y, Enter to save)
3. Repeat for all files


STEP 2: CONNECT TO SERVER
==========================================

ssh your_username@server_address

Enter your password when prompted.


STEP 3: VERIFY FILES ARE UPLOADED
==========================================

ls -la

You should see:
part1a.c
part1a_answer.txt
part1b_answer.txt
part2.c
part2_answer.txt
part3.c
part4.c


STEP 4: RUN THE LAB ASSIGNMENTS
==========================================

PART 1A - Switch Case Analysis
-------------------------------
cat part1a_answer.txt

Try to compile (will fail):
gcc -o part1a part1a.c


PART 1B - String Functions
---------------------------
cat part1b_answer.txt


PART 2 - strlen vs sizeof
--------------------------
gcc -o part2 part2.c
./part2
echo ""
cat part2_answer.txt


PART 3 - Case Swapping
----------------------
gcc -o part3 part3.c
./part3

When prompted, type: AbCdefGuM
Press Enter

Expected output: aBcDEFgUm


PART 4 - Cheese Sorting
-----------------------
gcc -o part4 part4.c
./part4


STEP 5: GENERATE OUTPUT FOR SUBMISSION
==========================================

Create a complete output file:

script lab_output.txt

Then run all commands:
echo "=== PART 1A ==="
cat part1a_answer.txt
echo ""

echo "=== PART 1B ==="
cat part1b_answer.txt
echo ""

echo "=== PART 2 ==="
gcc -o part2 part2.c
./part2
echo ""
cat part2_answer.txt
echo ""

echo "=== PART 3 ==="
gcc -o part3 part3.c
echo "Test input: AbCdefGuM"
echo "AbCdefGuM" | ./part3

gcc -o part4 part4.c

View the output:
cat lab_output.txt


STEP 6: DOWNLOAD OUTPUT (IF NEEDED)
==========================================

From your local machine:
scp your_username@server_address:~/lab_output.txt ./


TROUBLESHOOTING
==========================================

Issue: Permission denied
Fix: chmod +x part*.c

Issue: gcc not found
Fix: module load gcc  (or ask your instructor)

Issue: Compilation errors
Fix: Check that files were copied correctly
     Use: cat part1a.c | head -20

Issue: Cannot upload files
Fix: Check if you're in the right directory
     Use: pwd  (should show /home/your_username or similar)


QUICK COMMAND REFERENCE
==========================================

Connect:          ssh username@server
List files:       ls -la
Edit file:        nano filename
Compile:          gcc -o output filename.c
Run:              ./output
View file:        cat filename
Exit SSH:         exit
Copy to server:   scp file username@server:~/
Copy from server: scp username@server:~/file ./
