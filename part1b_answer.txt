Part 1b - String Functions Explanation:

1) strlen()
   - Purpose: Returns the length of a string (number of characters before null terminator)
   - Prototype: size_t strlen(const char *str)
   - Parameters: str - pointer to null-terminated string
   - Return Value: Number of characters in string (excluding null terminator)
   - Example: strlen("Hello") returns 5

2) strncmp()
   - Purpose: Compares first n characters of two strings
   - Prototype: int strncmp(const char *str1, const char *str2, size_t n)
   - Parameters: 
     * str1 - first string to compare
     * str2 - second string to compare
     * n - maximum number of characters to compare
   - Return Value:
     * 0 if strings are equal for first n characters
     * <0 if str1 is less than str2
     * >0 if str1 is greater than str2
   - Example: strncmp("Hello", "Help", 3) returns <0

3) strncpy()
   - Purpose: Copies up to n characters from source to destination
   - Prototype: char *strncpy(char *dest, const char *src, size_t n)
   - Parameters:
     * dest - destination buffer
     * src - source string
     * n - maximum number of characters to copy
   - Return Value: Pointer to destination string
   - Note: If src is shorter than n, dest is padded with null characters
   - Warning: May not null-terminate if src is >= n characters
   - Example: strncpy(dest, "Hello", 10) copies "Hello" and pads with nulls

4) strncat()
   - Purpose: Appends up to n characters from source to end of destination
   - Prototype: char *strncat(char *dest, const char *src, size_t n)
   - Parameters:
     * dest - destination string (must have enough space)
     * src - source string to append
     * n - maximum number of characters to append from src
   - Return Value: Pointer to destination string
   - Note: Always null-terminates the result
   - Example: If dest="Hi", strncat(dest, "World", 3) makes dest="HiWor"
