Part 2 Analysis:

QUESTION 1: Why are the two reported lengths different (5 vs 10)?

ANSWER:
strlen(str) returns 5 because it counts only the actual characters in the string "Gouda" until it reaches the null terminator '\0'. The string "Gouda" has 5 characters: G-o-u-d-a.

sizeof(str) returns 10 because it returns the total size of the array in bytes, which was declared as char str[10]. This is the allocated memory size, not the actual string length. The array has space for 10 characters, even though only 6 are used (5 for "Gouda" + 1 for null terminator).

QUESTION 2: Why is the cheese unknown?

ANSWER:
The cheese is "Unknown" because of how the if statement evaluates strncmp().

strncmp(str, "Gouda", 10) compares the first 10 characters of str with "Gouda". Since str only contains "Gouda" (5 characters + null terminator), both strings match for the content that exists.

When strings are equal, strncmp() returns 0.

In C, 0 is treated as FALSE in conditional statements. So "if (0)" evaluates to FALSE.

Therefore, the else branch executes, printing "Unknown cheese".

TO FIX: The condition should be "if (!strncmp(str, "Gouda", 10))" or "if (strncmp(str, "Gouda", 10) == 0)" to print the correct message when strings match.
